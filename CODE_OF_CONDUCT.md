# Código de conducta

Este proyecto adopta el [Contributor Covenant, versión 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).

En resumen: nos comprometemos a que la participación sea una experiencia libre de acoso para todas las personas, independientemente de su edad, tamaño corporal, discapacidad, etnia, identidad y expresión de género, nivel de experiencia, nacionalidad, apariencia, religión u orientación sexual.

- Usa un lenguaje acogedor e inclusivo; respeta puntos de vista distintos.
- Acepta la crítica constructiva y céntrate en lo mejor para la comunidad.
- No se tolera acoso, lenguaje ofensivo, ataques personales ni publicación de datos privados ajenos.

Para reportar un comportamiento inaceptable, abre un issue privado o contacta a las personas que mantienen el repositorio a través de GitHub. Todas las quejas se revisarán con confidencialidad.
